### What I work on at Nova Robotics

> The code is company-internal and kept private. Highlights:

| Project | What it does | Result |
|---|---|---|
| **Real-time drone tracker** | Detector-primary tracker (YOLOX + Kalman filter + re-ID verifier) on Raspberry Pi 5 + Hailo-8 NPU | **41 ms** camera-to-bearing latency |
| **Small-target detection** | Full-resolution tiling instead of downscaled frames | Small-drone recall **34% → 96%** |
| **Tracker evaluation kit** | Ground-truth annotator, scorer and resource profiler | False positives **42% → 23%** |
| **GPS-free precision landing** | ArUco pose estimation, Kalman filtering and MAVLink control on ArduCopter | Indoor autonomous landing |
| **PadNet** | 3.3M-parameter CNN landing-pad corner detector, compiled for Hailo-8 | Fallback when classical detection fails |
| **NovaROS** | Dockerized drone-control platform: ROS 2, MAVROS, FastAPI | Telemetry, control and vision services |
| **On-drone surveillance** | INT8 YOLOX-tiny detection of people, animals and vehicles | Push alerts over 4G |
